Tutorial I am following from Valem Tutorials, to learn more about using the Meta XR All-in-One SDK.

In this game you spawn ghosts outside of the player's room. The ghosts will walk towards orbs that the player needs to defend. They can do this by shooting the ghosts. The ghosts will become visible when you point a flashlight at them.
